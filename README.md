# ESNAD NEXT

إعادة تصميم وتطوير موقع شركة إسناد المالية — https://www.esnadadvisory.sa

## ما يحتويه هذا المستودع

| المسار | المحتوى |
|---|---|
| `wp-content/themes/esnad-next/` | القالب الجديد (RTL أولًا، عربي/إنجليزي) |
| `wp-content/plugins/esnad-core/` | الخدمات، الوثائق التنظيمية، النماذج، Schema، إعدادات الشركة |
| `wp-content/mu-plugins/` | إعدادات Staging (منع الفهرسة، تعطيل البريد الخارجي) |
| `docs/` | نظام التصميم، خطة النقل، خطة الإطلاق والرجوع |
| `tools/` | سكربتات WP-CLI لنقل المحتوى |

## ما لا يُرفع أبدًا

قاعدة البيانات، `wp-config.php`، مجلد `uploads` (يحتوي ملفات عملاء)، النسخ الاحتياطية، نواة WordPress والإضافات الخارجية. راجع `.gitignore`.

## البيئات

- **Production:** `www.esnadadvisory.sa` — لا يُنشر عليه شيء بدون موافقة صريحة.
- **Staging:** دومين Hostinger مؤقت، محمي بكلمة مرور، `noindex`، البريد الخارجي معطّل.
